# Hi, I'm Vinay

I am an AI and automation developer in the Greater Toronto Area. I build workflow automations, integrations and AI agents for business teams, then train people to use them.

## What I work with

- **Automation and integration:** Power Automate, Power Apps, n8n, Zapier, REST APIs, webhooks, MS Graph API, HubSpot, Zoho CRM
- **AI and agents:** Azure OpenAI, OpenAI API, Claude, Gemini, LangChain, LangGraph, MCP, RAG, human review steps and quality checks
- **Programming and data:** Python, FastAPI, SQL Server, SQLite, PostgreSQL, Docker, Git, GitHub Actions

I design the systems and build them with AI coding assistants such as GitHub Copilot, and I test and review everything before it ships.
